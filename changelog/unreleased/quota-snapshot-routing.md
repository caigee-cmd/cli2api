### English

- WorkBuddy quota again fills a missing used count from the pack size, and raises the total when the account dosage is larger than the pack sum. An empty pack list stays unknown instead of marking the account out of credits.
- Command Code still shows only the upstream 5-hour and weekly windows. Spending the 5-hour window no longer blocks the account while the weekly window has credits left.
- A failed Codex usage probe keeps the windows last reported by a chat response. A ChatGPT sign-in still has no usage probe, so it does not replay an old window.

### 中文

- WorkBuddy 额度再次在缺少已用数时用包大小减去剩余来补齐，并在账号总量大于包合计时抬高总量。包列表为空时保持未知，不再把账号记成额度耗尽。
- Command Code 仍然只显示上游的 5 小时和每周窗口。5 小时窗口用完时，只要每周窗口还有额度，账号就不会被挡住。
- Codex 用量探测失败时保留上一次聊天响应记下的窗口。ChatGPT 登录没有用量探测，不再把旧窗口当成当前额度。
